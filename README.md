# Reel Maker

Turn a text script into a vertical animated reel with a talking cat. Runs fully in the browser.

- Website: GitHub Pages serves `index.html` from the repo root.
- Android app: the workflow in `.github/workflows/android.yml` builds an APK on every upload (Actions tab, newest run, Artifacts).

Files in the repo root: index.html, sw.js, manifest.json, icon.svg, package.json, capacitor.config.json, README.md
Plus: .github/workflows/android.yml
